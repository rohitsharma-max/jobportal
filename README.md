# Internship & Job Listing Portal

A beginner-level **MERN** (MongoDB · Express · React · Node) full-stack project.
Users can browse internship/job opportunities, search and filter them, view details, and
submit applications. Admins can add, edit, and delete opportunities and view all applications.

## Tech stack
- **Frontend:** React.js (Vite) · React Router · Axios
- **Backend:** Node.js · Express.js
- **Database:** MongoDB (Mongoose)

**User:** view opportunities · search · filter by domain · view details · submit application · see confirmation
**Admin:** add / edit / delete opportunities · view applications
